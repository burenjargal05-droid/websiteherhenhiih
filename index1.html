Вэбсайт интернетэд хэрхэн гардаг вэ?

Компьютер дээр бичсэн index.html файл зөвхөн таны компьютерт л байдаг. Бусад хүн харахын тулд файлыг 24 цаг асаалттай байдаг компьютерт (хостинг, сервер) байрлуулж, түүнд хаяг өгөх хэрэгтэй.

1. Файл бэлтгэх→2. Хостинг→3. Хаяг (домэйн)→4. HTTPS
Хостинг

Таны файлыг хадгалж, хүсэлт ирэхэд хүргэдэг компьютер.

Домэйн

Хүний уншихад хялбар хаяг, жишээ нь example.mn.

DNS

Домэйныг серверийн IP хаяг руу чиглүүлдэг «хаягийн лавлах».

HTTPS

Холболтыг шифрлэж, хөтөчид «найдвартай» гэж харуулдаг гэрчилгээ.

Файлын нэрНүүр хуудсыг заавал index.html гэж нэрлэнэ. Сервер хаяг дээр өөр файл заагаагүй үед энэ файлыг нээдэг.

Хялбар арга: GitHub Pages

GitHub Pages нь GitHub дээр хадгалсан файлуудаас вэбсайт гаргаж өгдөг үйлчилгээ. Нийтийн (public) repository-д үнэгүй бөгөөд сервер, программ суулгах шаардлагагүй. Зөвхөн статик сайт (HTML, CSS, JavaScript) байрлуулна.

0 / 6 алхам хийгдсэн

  1. GitHub бүртгэл үүсгэх

    github.com/signup хаягаар орж и-мэйлээр бүртгүүлнэ. Хэрэглэгчийн нэр (username) нь сайтын хаягт орох тул сайн бодож сонго.

  2. Шинэ repository үүсгэх

    Баруун дээд буланд «+» → New repository. Нэрийг нь my-site гэх мэтээр өг, Public сонгоно. Хэрэв нэрийг USERNAME.github.io гэж өгвөл сайт шууд https://USERNAME.github.io хаягаар гарна.

  3. Файлаа байршуулах

    Repository дотор Add file → Upload files-ийг сонгож index.html (болон зураг, CSS файлууд) чирж оруулаад Commit changes дарна.

  4. Pages-ийг идэвхжүүлэх

    Settings → Pages хэсэгт Source: Deploy from a branch, Branch: main, хавтас / (root) сонгоод Save дарна.

  5. 1–2 минут хүлээх

    Нийтлэгдсэний дараа Pages хуудсанд «Your site is live» гэсэн мэдээлэл болон хаяг гарна. Ерөнхийдөө хаяг нь:

    https://USERNAME.github.io/my-site/

  6. Хөтөч дээр шалгах

    Хаягийг нээж сайт гарч байгаа эсэхийг шалга. Дараа нь файлаа солих бол дахин upload хийж commit хийхэд сайт автоматаар шинэчлэгдэнэ.

Командын мөрөөр (Git ашиглавал)

Git суулгасан бол файлаа дараах командаар илгээж болно:

git init
git add .
git commit -m "Анхны хувилбар"
git branch -M main
git remote add origin https://github.com/USERNAME/my-site.git
git push -u origin main
АнхаарахНийтийн repository-д байгаа бүх зүйлийг хүн бүр харна. Нууц үг, API түлхүүр зэргийг хэзээ ч оруулж болохгүй.

Бусад хялбар, үнэгүй хувилбарууд

GitHub-ээс гадна төстэй үйлчилгээнүүд олон бий. Үнэгүй багцын нөхцөл өөрчлөгдөж болох тул албан ёсны сайтаас шалгаарай.

Netlify

Сайтынхаа хавтсыг Netlify Drop хуудас руу чирээд тавихад л хаяг гарна.

Cloudflare Pages

GitHub-тай холбож автоматаар нийтэлнэ. Хурдан, дэлхий даяар түгээлттэй.

Vercel

GitHub-тай холбоход бэлэн. React, Next.js төслүүдэд түгээмэл.

GitLab Pages

GitHub Pages-тэй төстэй, GitLab дээр ажилладаг.

Хүнд арга: өөрийн сервер (VPS)

VPS (Virtual Private Server) нь түрээсэлсэн виртуал компьютер. Энд өөрөө бүгдийг тохируулах тул илүү хяналттай, дур зоргоороо программ суулгаж, backend, өгөгдлийн сан ажиллуулж болно. Гэхдээ Linux-ийн командын мөрийг мэдэж, аюулгүй байдал болон шинэчлэлтийг өөрөө хариуцна.

0 / 8 алхам хийгдсэн

  1. VPS түрээслэх

    Хостинг компаниас (DigitalOcean, Hetzner, Vultr, дотоодын хостинг гэх мэт) хамгийн бага багцтай Ubuntu LTS сервер захиал. Танд серверийн IP хаяг болон нэвтрэх мэдээлэл ирнэ.

  2. Серверт SSH-ээр нэвтрэх

    Компьютерийнхээ терминалаас:

    ssh root@SERVER_IP

    Аюулгүй байдлын үүднээс root-оор байнга ажиллахгүй, тусдаа хэрэглэгч үүсгэж SSH түлхүүрээр нэвтрэхийг зөвлөдөг.

  3. Систем шинэчлэх ба галт хана тохируулах

    sudo apt update && sudo apt upgrade -y
sudo apt install ufw -y
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable

    Анхаар: OpenSSH-ийг зөвшөөрөлгүйгээр галт ханыг идэвхжүүлбэл серверээс өөрийгөө түгжиж магадгүй.

  4. Nginx вэб сервер суулгах

    sudo apt install nginx -y
sudo systemctl enable --now nginx

    Хөтөч дээр http://SERVER_IP хаягийг нээхэд Nginx-ийн угтах хуудас гарна.

  5. Сайтын хавтас үүсгэж файл хуулах

    # серверт:
sudo mkdir -p /var/www/example.mn
sudo chown -R $USER:$USER /var/www/example.mn

# өөрийн компьютерээс:
scp -r ./site/* USER@SERVER_IP:/var/www/example.mn/

  6. Nginx-ийн тохиргоо бичих

    /etc/nginx/sites-available/example.mn файлд:

    server {
    listen 80;
    server_name example.mn www.example.mn;
    root /var/www/example.mn;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}

    Дараа нь идэвхжүүлж шалгаад дахин ачаална:

    sudo ln -s /etc/nginx/sites-available/example.mn /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

  7. Домэйныг серверт холбох

    Домэйн бүртгэгчийн DNS хэсэгт A бичлэг нэмж серверийн IP хаяг руу чиглүүл (дэлгэрэнгүйг дараагийн хэсгээс харна уу). DNS дэлхий даяар шинэчлэгдэхэд хэдэн минутаас хэдэн цаг хүртэл болдог.

  8. HTTPS гэрчилгээ авах

    Үнэгүй Let's Encrypt гэрчилгээг Certbot-оор авна:

    sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d example.mn -d www.example.mn
sudo certbot renew --dry-run

    Сүүлийн команд нь гэрчилгээ автоматаар сунгагдаж байгааг шалгана.

Серверийг хамгаалахТогтмол шинэчлэлт хийх, нууц үгээр нэвтрэхийг хаах (SSH түлхүүр), шаардлагагүй портыг хаах, нөөцлөлт (backup) хийх нь таны хариуцлага.

Домэйн ба HTTPS

Домэйн авбал сайт username.github.io гэсэн урт хаягийн оронд example.mn зэрэг өөрийн хаягаар гарна. Домэйныг бүртгэгч компаниас жилээр түрээслэнэ.

DNS бичлэгийн төрлүүд

БичлэгХэзээ хэрэглэхЖишээ
AДомэйныг IP хаяг руу чиглүүлэх (VPS-д)@ → 203.0.113.10
CNAMEДэд домэйныг өөр нэр рүү чиглүүлэхwww → USERNAME.github.io
AAAAIPv6 хаяг руу чиглүүлэх@ → 2001:db8::1

GitHub Pages-д өөрийн домэйн холбох

  1. Repository-ийн Settings → Pages → Custom domain хэсэгт домэйнээ бичиж Save дар.
  2. Домэйн бүртгэгчийн DNS дээр www дэд домэйнд CNAME бичлэгийг USERNAME.github.io руу чиглүүл.
  3. Үндсэн домэйн (apex) бол GitHub-ийн албан ёсны баримтад заасан A бичлэгүүдийг нэм.
  4. DNS шинэчлэгдсэний дараа Enforce HTTPS-г идэвхжүүл.
ШалгахIP хаяг, DNS бичлэгийн утгыг GitHub-ийн албан ёсны баримтаас (docs.github.com/pages) заавал шалгаарай. Интерфэйс, нөхцөл цаг хугацаанд өөрчлөгдөж болно.

Түгээмэл асуулт

Сайт нээгдэхгүй, 404 гарч байна. Яах вэ?

Нүүр файлын нэр яг index.html (жижиг үсгээр) эсэх, repository-ийн үндсэн хавтсанд байгаа эсэх, Pages-ийн branch зөв сонгогдсон эсэхийг шалга. Шинэчилсний дараа 1–2 минут хүлээнэ.

Өөрчлөлт сайт дээр харагдахгүй байна.

Хөтчийн кэшээс болж байж магадгүй. Ctrl+F5 дарж дахин ачаал. Мөн commit амжилттай хийгдсэн эсэхийг repository-оос шалга.

Зураг, CSS ачаалахгүй байна.

Файлын зам, том жижиг үсгийг шалга. GitHub болон Linux сервер том жижиг үсгийг ялгадаг (Logo.png ≠ logo.png).

Сайт дээрээ маягт илгээж, өгөгдөл хадгалах боломжтой юу?

Статик хостинг дээр backend байхгүй. Гэхдээ Formspree зэрэг гадны маягтын үйлчилгээ ашиглаж болно, эсвэл VPS дээр өөрийн backend ажиллуулна.

Хаанаас эхлэх нь дээр вэ?

Эхлэгчдэд GitHub Pages-ийг зөвлөдөг. Дараа нь шаардлага гарвал VPS-д шилжих боломжтой. Файлууд нь адилхан тул шилжилт хялбар.

Энэхүү гарын авлага нь танин мэдэхүйн зорилготой. Үнэ, нөхцөл, интерфэйс өөрчлөгдөж болох тул албан ёсны баримт бичгийг шалгаарай. GitHub Pages docs
